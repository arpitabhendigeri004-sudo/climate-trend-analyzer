## 📌 Overview

A data science project that analyzes climate data to identify trends, detect anomalies, and visualize patterns using Python and Streamlit.

## 🚀 Features

* 📈 Temperature Trend Analysis
* 🚨 Anomaly Detection
* 🔮 Forecasting (ARIMA Model)
* 🌐 Interactive Dashboard (Streamlit)

## 🛠️ Tech Stack

* Python
* Pandas, NumPy
* Matplotlib
* Scikit-learn
* Statsmodels
* Streamlit

## 📊 Project Structure

```
Climate-Trend-Analyzer/
│
├── data/
├── src/
├── app/
├── outputs/
├── images/
├── main.py
```

## ▶️ Run Project

### Run script:

```
python main.py
```

### Run dashboard:

```
streamlit run app/app.py
```
